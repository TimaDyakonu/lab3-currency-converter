# BNM Currency Converter (Конвертер валют НБМ)

Десктопное приложение с графическим интерфейсом (WPF / .NET 8) для конвертации валют по официальным курсам Национального банка Молдовы (BNM / НБМ).

---

## Возможности

- **Официальный источник курсов**: Автоматическая загрузка официальных ежедневных курсов валют в формате XML с сервера Национального банка Молдовы (`https://www.bnm.md`).
- **Учёт номинала валют**: Корректный расчёт курсов с учётом поля `Nominal` (например, 100 RUB или 100 JPY), нормализация к единице базовой валюты (MDL).
- **Конвертация в обоих направлениях и кросс-курсы**: Прямая конвертация к молдавскому лею (MDL), обратная конвертация и конвертация между двумя иностранными валютами через базовую валюту MDL.
- **Округление результатов**: Отображение результата с точностью до двух знаков после запятой (`0.00`).
- **Конвертация одинаковых валют**: Выбор одинаковой валюты в качестве источника и цели возвращает введенную сумму без ошибки.
- **Гибкий ввод сумм**: Поддержка как точки (`.`), так и запятой (`,`) в качестве десятичного разделителя.
- **Надежная валидация**: Защита от ввода пустых значений, букв, отрицательных чисел, нуля и некорректных разделителей без сбоев программы.
- **Устойчивость и кэширование (Offline fallback)**:
  - При отсутствии курсов на выходные или праздничные дни выполняется ретроспективный поиск за предыдущие дни (до 7 предшествующих календарных дней).
  - При отсутствии подключения к сети приложение не завершается аварийно, а использует локально сохраненный снимок курсов (`%LOCALAPPDATA%`), наглядно информируя пользователя о дате используемого курса.
  - Сохранение кэша переживает перезапуск приложения.

## Архитектура решения

Решение структурировано согласно принципу разделения ответственности (Separation of Concerns):

```text
CurrencyConverter.sln
├── src/
│   ├── CurrencyConverter.Core/      # Предметная область, парсер XML, конвертер, кэш, валидация
│   │   ├── Models/                  # Currency, ExchangeRate, RateSnapshot, ConversionRequest, etc.
│   │   ├── Parsing/                 # BnmXmlParser (System.Xml.Linq)
│   │   ├── Services/                # BnmRatesProvider, CurrencyConverter, BnmConstants, контракты
│   │   ├── Storage/                 # JsonRateCache (атомарное сохранение в JSON)
│   │   └── Validation/              # InputValidator
│   ├── CurrencyConverter.App/       # Десктопный интерфейс WPF (MVVM)
│   │   ├── Views/                   # MainWindow.xaml
│   │   ├── ViewModels/              # MainViewModel.cs
│   │   └── Services/                # AppComposition.cs, Commands.cs
│   └── CurrencyConverter.Tests/     # Набор модульных тестов xUnit
│       ├── App/                     # Тесты команд и состояний ViewModel
│       ├── Fixtures/                # Тестовые данные, заглушки HTTP и снапшотов
│       ├── Parsing/                 # Тесты парсера XML (номинал, ошибки, невалидный XML)
│       ├── Services/                # Тесты конвертера валют и провайдера (сеть, fallback)
│       ├── Storage/                 # Тесты сохранения и восстановления кэша
│       └── Validation/              # Тесты валидации граничных условий ввода
└── specs/                           # Спецификации SpecKit (spec.md, plan.md, tasks.md, etc.)
```

## Сборка и запуск

### 1. Сборка решения

В корневой директории проекта выполните:

```powershell
dotnet build
```

Сборка должна завершиться успешно без предупреждений и ошибок.

### 2. Запуск тестов

Для запуска полного набора автоматизированных тестов xUnit:

```powershell
dotnet test
```

Тестовый набор включает 80 тестов, покрывающих:
- Парсинг XML, обработку номиналов, дубликатов и некорректных структур данных.
- Прямую, обратную и кросс-валютную конвертацию, а также конвертацию одинаковых валют.
- Валидацию ввода (точки, запятые, пустые строки, буквы, нули, отрицательные числа, переполнение).
- Поведение при отсутствии сети, обработку таймаутов и аварийных сценариев.
- Ретроспективный поиск курсов выходных/праздничных дней (до 7 дней).
- Персистентность локального кэша JSON после перезапуска приложения и обработку поврежденного кэша.
- Логику состояний View/ViewModel (активность кнопки Convert, привязки данных).

### 3. Запуск приложения

Для запуска графического интерфейса:

```powershell
dotnet run --project src/CurrencyConverter.App
```

## Сценарии использования

1. **Базовая конвертация**:
   - Введите сумму (например, `100` или `12.50` или `12,50`).
   - Выберите исходную валюту (например, `EUR`) и целевую валюту (например, `MDL`).
   - Нажмите кнопку **Convert**.
   - В поле результата отобразится сумма, округленная до 2 знаков после запятой, дата примененного курса и источник (`National Bank of Moldova (BNM)`).

2. **Работа без интернета**:
   - После успешного запуска и сохранения курсов отключите сеть.
   - Приложение продолжит функционировать в штатном режиме, используя сохраненный локальный кэш и явно информируя о дате кэшированного курса.
